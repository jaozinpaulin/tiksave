## Sobre o Projeto

O **TikDownload** é uma aplicação web minimalista e de alta performance desenvolvida para permitir que usuários salvem conteúdos do TikTok diretamente em seus dispositivos (smartphones, tablets ou computadores) sem a necessidade de instalar aplicativos de terceiros.

---

## Principais Funcionalidades

- **Vídeos em Alta Resolução (HD):** Baixe vídeos do TikTok 100% livres de marca d'água no formato original MP4.
- **Carrossel de Fotos:** Reconhece posts com múltiplos slides de imagens e disponibiliza o download individual de cada foto em alta qualidade.
- **Conversor para MP3:** Extraia e salve a trilha sonora ou áudio viral de qualquer publicação em formato de áudio MP3.
- **Suporte Multi-idioma:** Interface totalmente traduzida para 12 idiomas (Português, Inglês, Espanhol, Francês, Alemão, Italiano, Indonésio, Turco, Russo, Árabe, Hindi e Japonês).
- **Progressive Web App (PWA):** Instale o site diretamente na tela inicial do seu celular como se fosse um aplicativo nativo.

---

## Tecnologias Utilizadas

- **HTML5 & CSS3** (Com variáveis customizadas e design responsivo em tema escuro/bege minimalista).
- **JavaScript (ES6+)** (Consumo de API assíncrona, manipulação de DOM e motor de internacionalização).
- **Phosphor Icons** (Biblioteca de ícones moderna e leve).
- **API TikWM** (Para extração de links diretos de mídia do TikTok).
