# TikSave - TikTok Downloader

Aplicação web minimalista para baixar vídeos do TikTok sem marca d'água (MP4) e extrair o áudio em alta qualidade (MP3).

## Tecnologias

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Phosphor Icons
- **Backend:** Node.js, Express, Axios, CORS

## Como Rodar o Projeto Localmente

1. **Instale as dependências:**
    ```bash
    npm install
    ```
